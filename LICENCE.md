## 🧩 About

**SCUM overlay Menu** is a curated list of SCUM open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot overlay viewer, map overlay
- **Quality-of-Life Helpers** — inventory notes, loot tracker, HUD notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Survival Helpers
- Loot overlay — visualize nearby loot markers
- Map Overlay — study island layout and points of interest
- Player HUD Notes — organize status and vitals on screen
- Movement Notes — record and review routes

### 🎨 Inventory & Loot
- Loot Tracker — catalog items and spawn notes
- Inventory Overlay — organize gear and supplies
- Container Notes — review storage layouts

### 🏋️ Practice Layout
- Base Building Notes — segment study on any layout
- Crafting Overlay — review recipe trees
- Config Presets — switch study profiles quickly

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
| `process_name` | String | `"SCUM.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Keep conservative defaults |
